# Scrapshift — Kickstarter visual kit

Working campaign identity for a retro 3D scrapyard simulator.

**Tagline:** Start with your bare hands. Build a scrapyard that works for you.

## Art direction

Aged ivory lettering, rust-orange machines, muted olive, charcoal shadows. Chunky late-1990s forms and worn industrial signage. Keep text clear and avoid heavy distortion.

Palette: ivory `#E8DDC4`, rust `#B75935`, olive `#69735B`, charcoal `#202927`.

## Usage

The scene illustrations are concept artwork, not gameplay screenshots. Keep their concept-art labels visible. Use the transparent logo over backgrounds with sufficient contrast. These are raster artwork masters; section dividers are editable SVGs.

No funding amount, reward price, delivery date, release platform, or finished feature is promised by this kit. Add reward and schedule graphics once those details are settled. The gameplay trailer and gameplay screenshots must come from the running prototype.

These images were created with the built-in image-generation tool. Disclose relevant AI use in the campaign. The working name has not been cleared for publication.

## Suggested campaign order

Cover → short pitch → The Game → Hands to Automation → real prototype footage → Development Plan → Rewards → About the Creator → Budget → Risks and Challenges.

Suggested image alt text should describe the picture and identify scene illustrations as concept art.
