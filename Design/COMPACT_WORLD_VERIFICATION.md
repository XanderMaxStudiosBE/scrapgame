# Compact yard world and original art

World/art agent contribution to stages A and B. The new fixed environment is 48 × 36 metres; office/shop/sales are southwest, receiving is southeast, and the entrance is south-centre. The rest is open construction space. The world builder never grants a generator, scrapper, storage, belts or fixed workbench pads. The gameplay model creates the modest movable starter equipment and scrap separately.

The creator's attached `ChatGPT Image Oct 1, 2026, 07_50_08 PM-1920x1450.jpg` is a design concept, not gameplay. Its “EXAMPLE LAYOUT – PLACE EQUIPMENT YOUR WAY” caption is followed: only infrastructure is fixed. No reference-image pixels or Windows paths are required by the game. The older scene, model sources, maps and campaign artwork remain intact.

## Implemented art and runtime views

- `CompactYardWorld.Build` returns four plain target roots for main-agent interaction metadata: Shop, Sales, Delivery and renewable Wire. The receiving crate is at (15, -13), clear of the starting car at (18, -10). A parked original truck and small fixed rain canopy occupy the back of the protected receiving area. Three fixed fluorescent fixtures match the main lighting agent's retained sun-plus-three-lamps budget.
- `CompactEquipmentVisuals` builds freely positioned/rotated equipment, portable components and stationary large scrap. Ghost mode omits colliders. It has no per-prop updates, rigidbodies, lights or authoritative inventory logic.
- Nine original metre-scale Blender meshes add the generator, Tier 1 scrapper, motor, compressor, refrigerator, delivery truck, plastic casing fragments, empty rubber insulation and softer boundary tree. Generator vents, analog meter, sockets, frame and wheels give it a recognizable silhouette. The scrapper has an open hopper, side motor, controls and separate front collection tray. Components use different shapes rather than the same coloured block.
- All new models reuse the existing recovered PropAtlas. Existing original FBXs, atlases, materials, metadata and source manifests are untouched. New records live in `compact_asset_manifest.json` and `compact_asset_audit.json`; the previous 31-model manifest remains separate. The existing import policy covers the new `ScrapshiftProps/Compact*.fbx` files.
- Nine meshes total 8,232 triangles; the largest is the 1,636-triangle delivery truck. Each has one material and at most 2,500 triangles. Coarse collision fits the shared build footprints. Static fixed scenery uses small regional batches. Two bounded, upward-facing ground meshes add dust, tyre wear and rough puddles with existing textures; they add no collision or lights.

## Checks executed

Blender 4.3.2 imported all nine exported FBXs: finite vertices/normals, metre dimensions, triangle budgets, UVs inside the shared atlas and one material passed. `python3 Tests/audit-compact-assets.py` checked binary headers and hashes against that actual import report; it passed. Python source compilation and C# syntax parsing passed.

`CompactWorldTests.cs` supplies 24 Unity EditMode cases for actual imports/material recovery, dimensions, available ground resources, open interior and starting-scrap clearance, placed/ghost collision, stationary large scrap and component policies. These are **unrun**: Unity is unavailable in this cloud environment. No Unity compile, shader/import result, collision, placement usability, FPS, player build or visual acceptance is established by the cloud checks.

`CompactStarterOverview.png` is a Blender render of actual exports in the compact manual-start layout. `CompactEquipmentExample.png` shows an example purchased generator/scrapper arrangement. Both carry visible “NOT UNITY GAMEPLAY” labels. Lighting/tone mapping are approximated and an extra broad preview fill is used; live Unity signs, HUD, interaction, shader behaviour and physics are omitted. The generator example does not imply advanced starting inventory.

Reproduce model authoring and checks from the repository root:

```sh
blender -b --python-exit-code 1 --python ArtSource/build_compact_assets.py
blender -b --python-exit-code 1 --python ArtSource/audit_compact_assets.py
python3 Tests/audit-compact-assets.py
MESA_SHADER_CACHE_DIR=/tmp/scrapshift-compact-mesa blender -b --python-exit-code 1 --python ArtSource/render_compact_preview.py
MESA_SHADER_CACHE_DIR=/tmp/scrapshift-compact-mesa blender -b --python-exit-code 1 --python ArtSource/render_compact_preview.py -- equipment
```

Only the independent new pack is regenerated by its authoring script. Do not run the old whole-pack authoring commands to refresh this world.
